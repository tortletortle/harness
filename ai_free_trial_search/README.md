# AI免费试用信息搜索系统

## 项目简介
本系统用于搜索、采集、整理AI相关免费试用信息，为用户提供统一的查询、筛选、导出服务。

## 架构组件
1. 前端交互组件：负责用户查询输入、筛选条件设置、结果展示与导出
2. 搜索调度组件：负责分发搜索请求到不同搜索工具，管理搜索任务队列
3. 多源数据采集组件：调用搜索、网页抓取工具获取AI免费试用相关信息
4. 数据清洗组件：对采集的原始数据进行去重、无效信息过滤、结构化处理
5. 信息聚合组件：整合不同来源的AI服务免费试用规则、有效期、适用场景等信息
6. 本地存储组件：存储历史搜索结果、常用AI服务信息，支持快速检索
7. 人工校验组件：对存疑的免费试用信息进行人工验证，保证准确性

## 核心流程
1. 用户在前端提交查询请求
2. 调度组件将请求分发至搜索工具，触发数据采集
3. 采集组件获取原始搜索结果后，传输至清洗组件进行结构化处理
4. 清洗后的有效信息由聚合组件整合统一格式，存储至本地存储组件
5. 前端从存储组件拉取聚合后的结果，展示给用户，支持用户触发筛选、导出操作
6. 对存疑的信息，前端提交人工校验请求，由人工校验组件验证后更新存储

## 使用方法
运行main.py即可启动系统核心流程。
