工作区健康检查 / 设计说明
目标：将项目扫描、依赖检查、测试结果组织为一份可审阅的报告。
  • 只处理当前工作区，不扫描凭据目录。
  • 先读取配置与测试入口，再请求执行授权。
  • 测试脚本可能生成文件；审批中展示命令、范围和原因。
  • 命令获批不代表检查成功，最终结果以真实执行事件为准。
设计启发：将“意图”和“执行证据”分开，避免 AI 解释取代真实状态。
