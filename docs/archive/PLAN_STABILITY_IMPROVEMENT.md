### 1. 优化 Prompt（已完成）

**改进内容：**

**优化前：**
- 普通的文本描述
- 没有强调 JSON 格式要求
- 示例不够清晰

**优化后：**
```
⚠️ 重要：必须返回合法的 JSON 格式，不要添加任何解释文字。

✅ JSON 规则：
1. 所有字符串用双引号 ""
2. 最后一个元素后不要有逗号
3. outputs 可以是 null 或 {}
4. inputs 必须是对象 {}
5. 确保所有括号都正确闭合

⚠️ 只返回 JSON，不要添加任何解释文字或 markdown 标记！
```

**效果：**
- 使用表情符号和视觉标记吸引注意
- 明确列出 JSON 规则
- 强调不要添加解释文字
- 提供清晰的示例

### 2. JSON 修复逻辑（已完成）

**实现功能：**

创建了 `JSONFixer` 工具类，能够修复：

1. ✅ **未闭合的字符串** - 自动添加缺失的引号
2. ✅ **尾部逗号** - 移除 } 和 ] 前的逗号
3. ✅ **单引号** - 转换为双引号
4. ✅ **Markdown 标记** - 提取 JSON 代码块
5. ✅ **未加引号的键** - 添加引号
6. ⚠️ **未闭合的括号** - 部分支持（83% 成功率）

**修复流程：**
```
1. 尝试直接解析
   ↓ 失败
2. 提取 JSON 代码块
   ↓ 失败
3. 修复未闭合字符串
   ↓ 失败
4. 修复尾部逗号
   ↓ 失败
5. 修复未加引号的键
   ↓ 失败
6. 修复单引号
   ↓ 失败
7. 修复未闭合括号
   ↓ 失败
8. 返回错误
```

**测试结果：**
- 6个测试用例，5个通过（83%）
- 结构验证：4/4 通过（100%）

**文件：** `python/utils/json_fixer.py`
