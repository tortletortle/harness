```yaml
  stepfun: "https://api.stepfun.com/v1"
```

## 🔍 功能详细说明

### 1. 新建任务

**功能：**
- 输入项目需求描述
- AI 自动生成设计书
- 评估项目难度
- 分析技术栈

**提示：**
- 尽量详细描述功能
- 说明技术偏好（如：用 Python、React 等）
- 提到目标用户和使用场景

**示例需求：**
```
制作一个待办事项管理应用：
- 功能：添加、删除、标记完成
- 技术：React + Node.js + SQLite
- 界面：简洁的 Web 界面
- 目标：个人使用，本地运行
```

### 2. 设计书审阅

**查看内容：**
- **难度评估**：项目难度等级和原因
- **架构设计**：
  - 系统组件列表
  - 技术栈推荐
  - 数据流程图
- **工具评估**：
  - 可用工具（绿色）
  - 缺失工具（红色）
  - AI 建议

**操作：**
- **批准**：自动生成执行计划
- **拒绝**：返回修改需求

### 3. 执行计划

**查看内容：**
- 按阶段组织的步骤列表
- 每个步骤的详细信息：
  - 步骤描述
  - 使用的工具
  - 输入参数
  - 预期输出

**操作：**
- 展开/折叠阶段查看详情
- 点击 "开始执行" 运行计划
- 执行中可暂停 / 恢复，可跳过单个步骤，失败后可回滚到指定步骤重试（旧分支步骤自动废弃）

### 4. 工具管理

**查看内容：**
- 系统内置的 7 个工具：
  1. **FileCreator** - 创建文件
  2. **CommandRunner** - 执行命令
  3. **PackageInstaller** - 安装依赖
  4. **GitOperator** - Git 操作
  5. **TextEditor** - 编辑文本
  6. **WebFetcher** - 获取网页
  7. **ManualTool** - 手动操作

**工具卡片显示：**
- 工具名称和描述
- 能力列表（展开查看）
- 需求说明
- 工具 ID

### 5. 历史记录

**功能：**
- 查看所有历史设计书
- 查看所有历史执行计划
- 快速切换到历史项目

**操作：**
- 切换 Tab（设计书/执行计划）
- 点击项目卡片查看详情

### 6. 实时日志

**功能：**
- WebSocket 实时推送日志
- 彩色分级显示
- 自动滚动到最新
- 显示时间戳

**日志级别：**
- **INFO**（蓝色）：一般信息
- **SUCCESS**（绿色）：成功操作
- **WARNING**（黄色）：警告信息
- **ERROR**（红色）：错误信息

## 🐛 常见问题

### Q1: 生成设计书很慢？
**A:** 正常现象，AI 生成需要 10-30 秒，请耐心等待。查看底部日志了解进度。

### Q2: WebSocket 连接失败？
**A:** 
1. 确认后端正在运行（访问 http://localhost:8000）
2. 刷新浏览器页面
3. 检查浏览器控制台（F12）的错误信息

### Q3: 执行失败怎么办？
**A:**
1. 查看日志面板的错误信息
2. 检查工具是否可用（工具页面）
3. 确认 API 密钥配置正确

### Q4: 如何更换端口？
**A:**
- 后端：编辑 `scripts/start_api.py`，修改 `port=8000`
- 前端：编辑 `frontend/vite.config.ts`，把 `port: 3000` 改成其他端口（如 3001）
- 前端 API 地址：编辑 `frontend/src/api/client.ts`，修改 `API_BASE`

### Q5: 如何停止服务？
**A:**
- 后端：在终端按 `Ctrl+C`
- 前端：在终端按 `Ctrl+C`
- 或者直接关闭终端窗口

## 🎓 进阶使用

### 同时处理多个项目

1. 在 "新建任务" 创建第一个项目
2. 审批后开始执行
3. 执行期间，点击 "新建任务" 创建第二个项目
4. 在 "历史记录" 中切换项目

**注意：** 目前同一时间只能执行一个计划。

### 导出设计书

1. 在设计书页面
2. 按 `Ctrl+A` 全选内容
3. 按 `Ctrl+C` 复制
4. 粘贴到文本编辑器保存

### API 调用

如果想用脚本调用 API：

```python
import requests

TOKEN = open('config/api_token').read().strip()
headers = {'Authorization': f'Bearer {TOKEN}'}

# 生成设计书
response = requests.post('http://localhost:8000/api/design',
    headers=headers,
    json={'user_request': '制作一个计算器应用'})
design = response.json()['design']
print(design['design_id'])
```
