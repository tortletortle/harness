【关键发现总结】
================================================================================

1. web_fetcher 的 bug 是致命的
   - 推断指令 'fetch' 根本不存在
   - 导致所有未明确指定 instruction 的 web_fetcher 步骤都会执行失败
   - 错误信息：未知指令: fetch

2. text_editor 和 command_runner 的 bug 是架构问题
   - 推断指令与声明不一致，但工具的 execute() 中有兼容处理
   - 导致系统能工作，但架构混乱，容易引发维护问题
   - 存在被意外修改或移除的风险

3. 数据库有 4 个脏数据需要清理
   - 旧格式状态值未被迁移
   - 会导致 API 因 Pydantic 验证失败返回 404

4. 测试框架的假阳性问题
   - 现有的 test_instruction_inference.py 没有从注册表动态获取合法指令
   - 导致它断言的都是错误的指令名，仍然显示通过

【测试结论】
================================================================================

严重程度: 高 (HIGH)

web_fetcher 的推断指令 bug 是一个致命问题，已通过多个测试维度验证：
  ✗ 声明不包含推断指令
