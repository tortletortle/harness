
   ```bash
   curl http://127.0.0.1:8000/api/plan/<plan_id>
   # 预期响应格式:
   {
     "plan": {
       "id": "...",
       "design_id": "...",
       "segments": [...],
       "steps": [  // 关键! 这个数组必须存在且不为空
         {
           "id": "...",
           "segment_id": "...",
           "order": 1,
           "name": "...",
           "tool": "...",
           "parameters": {...},
           "status": "Pending"
         },
         ...
       ]
     }
   }
   ```

   ```bash
   # 预期: 开始执行步骤
   ```

   ```bash
   curl http://127.0.0.1:8000/api/step/<step_id>
   # 预期: {"step_id": "...", "status": "Running|Completed|Failed"}
   ```

- ✅ 所有端点返回 200/201 状态码
- ✅ `/api/plan/<plan_id>` 响应包含 `steps` 数组
- ✅ `steps` 数组长度 > 0

如果发现以下问题,请立即报告:

1. ❌ **计划步骤为空** - 这表明修复失败,需要立即处理
2. ❌ **"Invalid instruction" 错误** - Executor 无法解析步骤
3. ❌ **数据库步骤缺失** - 步骤未正确保存到 steps 表
4. ❌ **API 响应缺少 steps 数组** - API 格式化函数有问题
5. ⚠️ **执行超时** - 性能问题,需要优化
